# 📖 Scrapbook Web Application

A full-stack web application built with **Flask** and **MySQL** that lets users log in, create personalized scrapbooks, and save memorable photos with custom captions and dates.

---

## ✨ Features

- **User Authentication:** Secure registration and login using hashed passwords (`werkzeug.security`).
- **Scrapbook Management:** Create and delete customized scrapbooks.
- **Memory Gallery:** Upload photos with custom captions and dates attached to specific scrapbooks.
- **RESTful API:** Clean API endpoints handling scrapbooks and memory CRUD operations.

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask, PyMySQL, Werkzeug)
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Database:** MySQL
